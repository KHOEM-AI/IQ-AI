# Seed sound library

30 synthetic WAV sounds (3 per category, 22.05 kHz, mono, 16-bit, CC0) in `sounds/seed/`.
They are generated by code, so they are rough approximations (e.g. the dog bark and
laugh are not real recordings). Use them to test the library, search and the 10-category
structure. Replace with real, licensed recordings as the library grows.

Regenerate (deterministic):

    node scripts/generateSeedSounds.mjs

Files: `src/sound/synth.mjs` (helpers), `src/sound/seedSounds.mjs` (the 30 sounds),
`sounds/seed/catalog.json` (metadata, validated by `src/sound/schema.mjs`).
`storageKey` is relative to `sounds/seed/`.
